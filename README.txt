AZHARIX Academy website — VS Code setup

1. Extract AZHARIX_IT_Academy.zip.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted AZHARIX_IT_Academy folder.
4. Open index.html in your browser, or install the Live Server extension and select "Open with Live Server".
5. Update courses, durations and sample prices in script.js.
6. In index.html, update the demo email and location.
7. In script.js, replace hello@azharix.example in the mailto handler with your real email.

Important:
- Course prices are sample estimates in Pakistani rupees, not verified institute fees.
- Contact form opens the user's email application; it does not store data or process payments.
- Google Fonts needs an internet connection; fallback fonts are provided.
